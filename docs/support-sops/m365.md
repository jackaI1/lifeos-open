# Microsoft 365 reminders and sync

For Microsoft 365 sync, follow integrations/m365/README.md to configure the
SharePoint list and Microsoft account permissions. Sync is one-way and runs
only when requested. It does not change LifeOS records.

If Teams or Outlook reminders are missing, check that the task has a deadline
tomorrow and that the imported daily reminder workflow is enabled. Tasks without
a deadline stay in the list but do not produce a reminder. Check the list before
re-running sync. Do not paste access tokens into a ticket. Ask the account owner
to review missing permissions; this assistant cannot grant them or send messages.
