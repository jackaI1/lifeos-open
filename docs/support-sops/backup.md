# Save a workspace backup before upgrading

To save a backup before an upgrade, open Settings and save a complete workspace
backup. Keep the downloaded backup somewhere separate from the running workspace.
Check the backup before upgrading. A database copy alone does not include all
uploaded files.

If data is already missing or a restore might overwrite current work, stop and
ask the workspace owner to review recovery. This assistant cannot restore or
delete data. Use the documented restore command only after checking the backup
and destination with the owner.

Full instructions: docs/local-workspace.md and docs/self-host-linux.md.
