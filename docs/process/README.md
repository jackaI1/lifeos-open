# Process

Lightweight Scrum for LifeOS. One maintainer plus AI coding agents, so the ceremonies are short and the artefacts live in GitHub.

## Skills demonstrated

- **Agile / Scrum**: backlog refinement into user stories with acceptance criteria and story points, a two-week milestone, a Definition of Done, review and retrospective templates, and PRs linked to issues so progress is visible. Files: `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md`, `docs/process/`.
