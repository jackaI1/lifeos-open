# Text experiment details

The character model uses a causal decoder block: each position attends only to earlier characters, then a feed-forward layer transforms its representation. It uses a fixed 64-character context and averages cross-entropy over tokens. Each device computes a local gradient; `pmean` averages those gradients before the same SGD update. Equal shard sizes make this the same as a full-batch mean. The test checks both loss and all gradient leaves. The checkpoint contains the parameters, vocabulary, step and NumPy sampling state; the learning rate and architecture are fixed in the script. Validation uses a fixed sample of 128 windows from the final 10% of the corpus, so perplexity is an estimate rather than a full-corpus score.

The review classifier embeds IMDB token IDs and positions, applies two-head self-attention and a feed-forward layer, and predicts a sentiment probability. The independent IMDB test split is used only for evaluation. It exports a TensorFlow SavedModel with an `int32` `[batch, 128]` signature. The REST integration test trains on 256 reviews, saves in-process predictions, starts the official TensorFlow Serving image, and compares the returned values with a numerical tolerance. It measures 20 batched requests after readiness. This is an end-to-end smoke test, not a throughput study; network and machine load affect latency. The IMDB and Shakespeare datasets are downloaded at runtime, so these experiments require network access. The existing weather tests remain offline.
