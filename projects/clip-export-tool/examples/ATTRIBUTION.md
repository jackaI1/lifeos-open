# Sample footage

`trami.mp4` contains ten seconds, starting eight seconds into **TEMPEST-D / RaInCube Sees Typhoon Trami**, released December 15, 2020.

Credit: **NASA's Scientific Visualization Studio**. Visualisation by Alex Kekesi; full credits and context are on the [original item page](https://svs.gsfc.nasa.gov/4859/).

- [Original MP4](https://svs.gsfc.nasa.gov/vis/a000000/a004800/a004859/tempestD_raincube_comp2_1080p30.mp4)
- [NASA SVS reuse policy](https://svs.gsfc.nasa.gov/help/): its content is public domain unless otherwise noted. This item has no exception listed. NASA endorsement is not implied.

I trimmed and reduced the video to 640 × 360 pixels to keep this repository small. The original file has no audio. I added a quiet 440 Hz test tone generated by FFmpeg so the example also exercises loudness normalisation. The tone is a test signal, not sound recorded by the satellite. The captions are my descriptions of the visualisation, not a transcript from NASA.

To reproduce the bundled file after downloading the original as `nasa-original.mp4`:

```sh
ffmpeg -hide_banner -nostdin -ss 8 -i nasa-original.mp4 \
  -f lavfi -i 'sine=frequency=440:duration=10' -t 10 \
  -vf 'scale=640:360,fps=30' -af volume=0.1 \
  -c:v libx264 -crf 25 -preset fast -threads 2 \
  -c:a aac -ar 48000 -ac 2 -map_metadata -1 \
  -movflags +faststart examples/trami.mp4
```
