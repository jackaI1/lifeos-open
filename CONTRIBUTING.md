# Contributing

Use Node.js 24 or newer. Run `npm ci`, then `npm run build`, `npm test`, `npm run lint` and `npm run typecheck`. Run `npx playwright install chromium` once and `npm run test:smoke` for browser coverage.

Use fictional fixtures and a fresh browser context. Keep personal records, credentials, local databases, recordings, exports and diagnostic screenshots containing private content out of pull requests. New integrations must have an offline substitute and explicit configuration. Do not let an assistant silently send messages, purchase anything or deploy changes.

Keep changes focused, document visible behavior and include meaningful regression coverage. Preserve third-party notices. Original project code is licensed under MIT; see LICENSE and THIRD_PARTY_NOTICES.md.
